# ソフトウェア設計

モジュール・クラス・パッケージの設計の良し悪しを判断し、保守性・再利用性の高い構造へ導くためのスキル。設計を新規に組むとき、既存コードをリファクタリングするとき、設計レビューで指摘の根拠が欲しいときに使う。トピックごとに reference を用意し、ここはその索引とする。

## いつ使うか

- モジュール・クラス・パッケージの分割が妥当かを判断したいとき
- 保守性・再利用性を高めるリファクタリングを検討するとき
- 設計レビューで、指摘の根拠となる観点・チェックリストが欲しいとき
