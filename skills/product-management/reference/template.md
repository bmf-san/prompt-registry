# プロダクト仕様書テンプレート

優先順位付けした要件をもとに、次の構成で仕様書を作成する。

```
# プロダクト仕様書

## 1. 概要
- プロダクト名 / 目的 / ターゲットユーザー

## 2. 背景・課題
- 解決したい課題 / 現状の問題点 / なぜ今取り組むべきか

## 3. ゴール・成功指標
- 目指す状態 / KPI・メトリクス / 成功の定義

## 4. ユーザーストーリー
- 主要なユーザーストーリー（優先度順） / 受け入れ基準

## 5. 機能要件
- 必須（Must Have） / 重要（Should Have） / あれば良い（Could Have）

## 6. 非機能要件
- パフォーマンス / セキュリティ / ユーザビリティ

## 7. 制約条件
- スケジュール / 予算 / 技術的制約

## 8. スコープ外
- 今回は対象外の項目（Won't Have） / 将来的な検討事項

## 9. リスクと対応策
- 想定されるリスク / 各リスクへの対応策
```
